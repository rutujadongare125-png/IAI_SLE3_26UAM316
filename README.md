
# BFS and DFS Algorithms

## Aim
To implement Breadth-First Search (BFS) and Depth-First Search (DFS) algorithms for graph traversal.

## Introduction
BFS and DFS are graph traversal algorithms used to visit vertices of a graph.

## 1. Breadth-First Search (BFS)
BFS visits vertices level by level. It uses a queue data structure.

## 2. Depth-First Search (DFS)
DFS explores a path as deeply as possible before backtracking. It uses a stack or recursion.

## Objectives
- To understand graph traversal.
- To implement BFS and DFS algorithms.
- To compare the working of BFS and DFS.

## Applications
- Web crawling
- Network traversal
- Pathfinding
- Social network analysis

## Technologies Used
- Programming Language: C / Python
- Algorithm: BFS and DFS

## Conclusion
BFS and DFS are important graph traversal algorithms. BFS explores level by level, while DFS explores deeply before backtracking.
